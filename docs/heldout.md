# Held-out run

Held-out seeds 9501 and 9502 ran once on 26 Nov 2026 with the code and settings the dev seeds ended on
(`reports/heldout.lock`). Every gate passed. The platform found 83% of the true top 20 young line-breakers
(dev: 78%) with rank correlation 0.97 (dev: 0.96); the assistant showed no wrong players and asked back on 8% of
requests (dev: 10%).

What moved: season totals did a little better on held-out (40% vs 33%), so the gap to the platform is a little
smaller than on dev; the ordering of every design is the same. Nothing was changed after the run.
